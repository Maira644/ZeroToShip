# Peer Project Collaboration Platform

## Phase 4 – Static User Interface

This project was developed as part of the **ZeroToShip Summer Activity 2026** organized by the **CIS Community, NED University**.

The objective of Phase 4 was to build the complete frontend interface using static mock data before integrating any backend functionality.

---

## Features

### Discovery Marketplace

- Responsive CSS Grid layout
- Project cards displaying:
  - Project title
  - Creator name
  - Description
  - Skill badges
  - Project status
  - Apply button

### Project Manager Dashboard

- Dashboard for project creators
- Applicant cards displaying:
  - Applicant name
  - University
  - Applied project
  - Skills
  - Applicant status
- Accept and Reject button assets

---
