# ZeroToShip | Summer Activity 2026

## Peer Project Collaboration Platform

This repository contains my work for the **ZeroToShip Summer Activity 2026**, organized by the **CIS Community**.

### Project Overview

The assigned project for this activity is the **Peer Project Collaboration Platform**.

The platform aims to help students from different engineering and computing disciplines collaborate on projects by allowing them to:

- Create and publish projects
- Specify required technical skills
- Discover ongoing student projects
- Apply to join projects
- Manage project applications

This repository documents the complete development process across multiple phases, from database design to the final integrated application.
